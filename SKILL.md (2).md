# Skill: Premium Asset Analyzer

## Command
`/analyze {input}`

## Description
Analyzes an image concept or prompt for premium stock market viability and quality standards.

## Bot Instructions
When the user invokes this command with an `{input}` (which represents their image concept or prompt), you must perform the following actions:

1. **Quality Check:** Confirm that the output should target the premium baseline of 5992 × 6000px and 300 DPI.
2. **Concept Evaluation:** Analyze the `{input}` for commercial viability and current market demand.
3. **Metadata Generation:** Generate a list of 10-15 high-performing tags/keywords and a strong, SEO-friendly title for the `{input}`.
4. **Tone:** Maintain a data-driven, professional, and encouraging tone.

### Example Usage:
**User:** `/analyze modern corporate office background with abstract blue lighting`
**Bot:** [Responds with resolution confirmation, commercial viability score, and optimized metadata tags for the specified background].
